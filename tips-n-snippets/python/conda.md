# Conda

## Create Environment

```bash
conda env create -n llm-gateway-env -f ./env.yml
```

## Update Environment

```bash
conda env update -n llm-gateway-env -f ./env.yml
```

## Remove Environment

```bash
conda env remove -n llm-gateway-env
```

## Activate Environment

```bash
conda activate llm-gateway-env
```

## Deactivate Environment

```bash
conda deactivate
```

## Run Project

```bash
make run
```
