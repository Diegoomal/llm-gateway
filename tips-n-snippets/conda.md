# Conda

## Create Environment

```bash
conda env create -f ./env.yml
```

## Update Environment

```bash
conda env update -f ./env.yml
```

## Remove Environment

```bash
conda env remove -n project-env
```

## Activate Environment

```bash
conda activate project-env
```

## Deactivate Environment

```bash
conda deactivate
```

## Run Project

```bash
make run
```
