# V5 Test Results

Date: 2026-05-14

Goal: validate the V5 fix for atomic idempotency and the added idempotency
observability.

## Summary

Result: PASS

The V4 failure was reproduced as a V5 acceptance test: 10 simultaneous requests
with the same `Idempotency-Key`. In V5, only one request executed successfully
and the other nine returned `425 Too Early` while the winner was still
`in_progress`.

Validated:

- unit/integration test suite;
- lint;
- rebuilt Docker container running the V5 code;
- atomic concurrent idempotency via real HTTP;
- sequential replay with the same key;
- conflict on same key with different payload;
- rejection of `Idempotency-Key` with streaming;
- idempotency metrics;
- idempotency logs with hashed key instead of raw key.

## Concurrent Idempotency

Command:

```bash
python3 - <<'PY'
import asyncio, httpx, time, json

payload = {
    "model": "llama3.2:1b",
    "provider": "ollama",
    "messages": [
        {
            "role": "user",
            "content": "Reply with exactly: v5-concurrent-idem-ok",
        }
    ],
}
key = f"v5-concurrent-{int(time.time())}"

async def main():
    async with httpx.AsyncClient(timeout=60) as client:
        async def one(i):
            r = await client.post(
                "http://localhost:8000/v1/chat/completions",
                headers={"Idempotency-Key": key},
                json=payload,
            )
            body = r.json()
            return {
                "i": i,
                "status": r.status_code,
                "id": body.get("id"),
                "detail": body.get("detail"),
                "content": (
                    ((body.get("choices") or [{}])[0].get("message") or {})
                    .get("content")
                ),
            }

        results = await asyncio.gather(*(one(i) for i in range(10)))

    print(json.dumps({
        "key": key,
        "results": results,
        "status_counts": {
            str(s): sum(1 for r in results if r["status"] == s)
            for s in sorted({r["status"] for r in results})
        },
        "unique_success_ids": sorted({r["id"] for r in results if r["id"]}),
    }, indent=2))

asyncio.run(main())
PY
```

## Sequential Replay

Command:

```bash
KEY="v5-sequential-$(date +%s)"
PAYLOAD='{"model":"llama3.2:1b","provider":"ollama","messages":[{"role":"user","content":"Reply with exactly: v5-sequential-ok"}]}'

curl -fsS http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $KEY" \
  -d "$PAYLOAD" > /tmp/v5-seq-1.json

curl -fsS http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
```

## Payload Conflict

Command:

```bash
KEY="v5-conflict-$(date +%s)"

curl -fsS http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $KEY" \
  -d '{"model":"llama3.2:1b","provider":"ollama","messages":[{"role":"user","content":"First payload"}]}' \
  >/tmp/v5-conflict-first.json

code=$(curl -sS -o /tmp/v5-conflict-body.json -w "%{http_code}" \
  http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $KEY" \
  -d '{"model":"llama3.2:1b","provider":"ollama","messages":[{"role":"user","content":"Different payload"}]}')

echo status=$code
cat /tmp/v5-conflict-body.json
```

Outcome: PASS
